# 《马楠：霜云方舟》美术升维与资产工业化规范（ART_SPEC v2.0）

> **强制适用范围**：自 **M1.5 美术升维专项** 起，覆盖开局场景全部重制以及 **M2–M6 所有新增建筑、道具图标、浮岛地貌、7 种生态云兽与 3 个 Boss**。
> **核心结论**：彻底放弃“纯代码 `fillRect` 硬拼建筑、角色与生物”，升级为 **「`imagegen` 精绘 2.5D 资产 ＋ Python 自动化去背对齐管线 ＋ 7 层电影级 Canvas 2D 光影与大气渲染」** 双轮驱动，目标是达到成熟独立游戏（对标《地心护核者 Core Keeper》×《风来之国 Eastward》×《饥荒》手绘质感）的实机观感。

---

## 一、M1 画面问题诊断（改什么必须直击要害）

1. **主体全是 `fillRect` 几何堆叠且像素颗粒不统一（Mixels）**：余烬主炉像横放的柱状图、小猫拿铁像方块盒、云海是大块马赛克噪点、角色/木板/箱子像素粗细各异，造成强烈廉价“程序味”。
2. **方舟像一块切边正方形棋盘贴在背景上**：四边笔直无护栏/包角/积霜，底部浮石只是一条平直灰带，缺少立体悬空锥底、垂挂冰凌与船底云雾投影。
3. **镜头过远 + 冷暖反差太弱**：7×7 方舟在 1280×720 里只占中心一小块；暴雪夜暗幕偏灰且缺少加色暖橙辉光与物体暖边反光；雪花只是稀疏 1px 小点；失温时缺少冰晶暗角视觉压迫。
4. **HUD 像后台调试面板**：底部常驻“已载入 JSON 存档”大黑框遮挡画面；快捷栏纯文字无图标；体温/生命/燃料缺少图形化进度槽。

## 二、锁定统一画风与画面铁律

### 2.1 风格基准
- **画风**：**高精 2.5D 手绘厚涂 / 精绘独立游戏插画风（Crisp Hand-Painted 2.5D Top-Down）**，细腻笔触 + 柔和深色手绘勾线，和马楠左上角现有高清头像（`head-0~3.png`）自然融合，不再强行用低分辨率粗像素方块。
- **视角铁律（绝不混搭）**：全部建筑、角色、云兽、浮岛物件严格锁定 **3/4 俯视角（俯角约 38°–45°）**，能同时看到顶面与正面厚度，严禁混入 90° 纯顶视或 0° 纯侧视素材。
- **轮廓与受光基准**：
  - 柔和深冷灰或深暖棕外轮廓（`#141E2B` / `#261A16`），严禁死黑 `#000000` 粗黑边；
  - 默认环境天光来自**左上方**（左上微带冷白/冰蓝天光，右下带柔和暗面）；暖源物体自带内部暖橙发光体，大面积环境暖光交由渲染引擎实时合成。
- **色温纪律**：
  - 冰寒与云海元素饱和度克制在 `18%–38%`（深冰蓝石墨 `#0C1520` / `#152436`、寒雾 `#7FA6C4`、霜雪 `#DCEBF5`）；
  - 暖色生命元素聚焦温润木色与琥珀暖橙（`#FFE8B3` / `#F28533` / `#9C3D1C`），严禁蓝紫渐变、荧光绿/荧光黄等廉价霓虹色。

### 2.2 资产分工红线（什么用图、什么用代码）

| 类别 | 制作方式 | 具体对象 |
|---|---|---|
| **精绘 PNG 资产** | `imagegen` 生图 → `scripts/process-art.py` 自动去背净边、锚点对齐、压缩入 `src/assets/art/` | 马楠 4 向精绘精灵、小猫拿铁（蜷睡/警戒/行走）、余烬主炉 Lv.1–4、储物箱、挡风墙/保温墙、火把柱、工作台/熔炉/灶台/热力塔/浮力核/捕网/温室/兽窝/炮台、木甲板与立体浮石边角件、漂流残骸、32×32 UI 道具图标、浮岛树木/矿脉/遗迹、7 种云兽、3 个 Boss、高精柔和云海层贴图 |
| **高阶程序化渲染** | Canvas 2D 混合模式（`multiply` / `screen` / `lighter`）+ 粒子系统 | 双通道冷暖光影与暖色反光、三景深斜向暴雪风丝、上升火星与烟囱缕烟、动态热力结霜覆层、抓钩铁链与抛物预瞄线、船底冷雾飘带、失温冰晶暗角、实体呼吸缩放/走路摇摆微动效 |

## 三、`imagegen` + `scripts/process-art.py` 工业化资产管线

### 3.1 生图 Prompt 强制规范（全部记录到 `art/prompts.json`）
1. **统一风格前缀**（所有单体物件共享，保证同源画风）：
   > `2.5D top-down 3/4 view (40 degree camera angle) hand-painted indie survival game sprite, inspired by Core Keeper and Eastward, crisp painterly cel brushwork, subtle dark slate-brown outline (#1b222c), tactile frost-weathered wood and cast-iron materials, soft top-left cool skylight, centered isolated full object with generous padding on a flat pure solid #FF00FF magenta background, NO ground cast shadow, NO text, NO frame, NO watermark`
2. **主角马楠专属约束**：
   - 生图时必须参考仓库 `../assets/character/design-sheet.jpg` 的真实特征：**短寸头青年男性、炭黑连帽防风冲锋衣（左胸极小浅灰 `A` 标）、黑色多袋工装裤、浅灰白运动鞋、右手提一盏发暖橙光的防风铁灯**；
   - 至少生成清晰 4 朝向（南/北/东，西向可镜像微调提灯手）精绘角色图，搭配程序化 4 帧步态起伏 + 肢体/提灯微摆（或 2–4 帧精绘步态板），实机尺寸清晰锐利。
3. **小猫「拿铁」专属约束**：
   - 暖焦糖浅咖橘白相间的蓬松小猫（可爱圆润轮廓、明显三角小耳与蓬松尾巴），至少具备 **蜷缩睡姿** 与 **站立/炸毛警戒姿** 两套精绘精灵。
4. **体积控制硬红线（防 Git 撑爆）**：
   - 严禁将 `1024×1024` 未裁切原图提交进 Git！原图只在云端临时目录处理；
   - 正式入库（`src/assets/art/`）必须经过裁剪缩放与 PNG 优化：
     - UI 图标：`48×48` 或 `64×64`（显示为 `28–32px` 视网膜锐利）
     - 单格物件（木箱/残骸/火把/挡风墙/拿铁）：`96×96` ~ `128×128`
     - 主角马楠与中型云兽：`128×128`（单帧）
     - `2×2` 大型建筑（余烬主炉/温室/兽窝）与巨兽 Boss：`192×192` ~ `256×256`
     - 无缝云海贴图：`1024×576` WebP/轻量 PNG（≤ 180 KB）
   - **全游戏终版资产总体积控制在 `≤ 4.5 MB`**；单张精灵压在 `15–90 KB`。

### 3.2 `scripts/process-art.py` 必须实现的 5 个步骤
1. **Chroma-Key 精准去背 + 溢色剥离（Defringe）**：移除 `#FF00FF`（或纯绿幕）背景，对半透明 1–2px 边缘做洋红/绿色通道净边消除，**杜绝任何粉边、绿边、脏白边**。
2. **紧裁 + 脚底锚点标准化**：裁剪多余透明边，居中放入规范尺寸画布，自动将物体底部重心落点写入 `src/assets/art/manifest.json`（含 `anchorX`, `anchorY`, `tileW`, `tileH`）。
3. **色彩统一校准**：轻微压平过度刺眼的高饱和像素，使冷暖色域贴合 `palette.ts`。
4. **无损/量化压缩**：输出轻量透明 PNG（或 WebP + PNG 兼容）供 Vite 打包及 `file://` 双击包稳定加载。
5. **自动生成审片拼版图（`artifacts/art-review-sheet.png`）**：将本批所有正式素材同时摆在**浅灰棋盘底**与**深冰蓝底**上生成高对比拼版审片图。

### 3.3 Dot 强制自审流程与兜底条款
- **强制肉眼验收**：每批素材产出后，Dot **必须先亲自打开 `art-review-sheet.png` 逐个检查**：① 无脏边粉边 ② 全部为统一 3/4 俯视角 ③ 拿铁/主炉/马楠/物件轮廓一眼可辨且讨喜 ④ 体积比例协调。凡不合格单件立即调 Prompt 重做，**严禁带病接入游戏**。
- **若云端环境无生图工具权限**：**严禁擅自降级回 `fillRect` 代码硬画交差！** 必须立刻停下并向用户汇报，由用户授权工具或把外部生图包上传至 Google Drive 后由 Dot 走 `process-art.py` 自动接入。

## 四、7 层电影级 Canvas 2D 渲染管线升级规格

所有渲染层从下到上严格按 **L0 → L6** 合成：

1. **L0 · 柔和高空大气云海（告别马赛克）**
   - 废除低分辨率马赛克云，改用高精柔和云海贴图 + 3 层视差漂流 + 顶底冰蓝大气景深渐变；暴雪夜加入微弱冷青极光丝带与远方若隐若现的浮冰山剪影。
2. **L1 · 立体浮空方舟结构（告别“切边正方形”）**
   - **默认镜头拉近**：基准单格显示尺寸从 `40px` 提升至 **`56–64px`**（支持鼠标滚轮在 `44px–80px` 间缩放），让 7×7 开局方舟占据屏幕中心约 `45%–52%` 黄金比例。
   - **立体浮石锥底**：方舟底边与两侧绘制带高低错落的浮空岩锥、垂挂半透明冰凌、岩缝极微弱青蓝浮力晶光，并在船体下方叠加半透明冷雾漂移与深色云海投影。
   - **木甲板 4 变体 + 自动外缘构件**：木板使用精绘纹理（含 4 种拼缝/钉头/风化变体，消除机械重复）；外边缘自动补齐**木护栏、铁包角、角柱与系缆桩**（留出抛钩口）。
   - **实时热力结霜覆层**：读取 `heatGrid`，`< 8°C` 的甲板与外缘按冷度自动叠加半透明霜雪结晶纹理与白霜边缘；暖区自动融化露出温润暖木，**让冷暖边界肉眼直读**。
3. **L2 · 统一接触阴影与方向投影（消除“贴纸感”）**
   - 所有建筑、箱子、主炉、马楠、拿铁、云兽脚下统一画柔和深冷椭圆接触影（`rgba(8, 16, 28, 0.44)`），并在暖炉照射下向背光方向拉出极轻微柔和长影。
4. **L3 · Y-Sort 精绘实体层 + 程序化微动效**
   - 建筑、墙体、主角、拿铁、云兽按脚底世界 `y` 坐标统一排序，实现真实 2.5D 前后遮挡；
   - 精绘静物叠加呼吸微动效：主炉炉膛叠绘多层摇曳火舌与烟囱缕烟、火把叠绘火苗与火星、马楠/云兽待机呼吸微缩放（`1.00 ↔ 1.03`）与走路轻微左右倾摆（`±2.5°`）、漂流残骸随云流微幅上下浮沉。
5. **L4 · 电影级双通道冷暖光影（视觉灵魂）**
   - **通道 A（冷色环境暗幕）**：白昼 `0.08` 轻冷雾、黄昏 `0.34` 暮蓝、暴雪夜 `0.68–0.74` 深邃冰蓝（`#091829`）、大寒潮 `0.82`，通过径向柔光扣除暖区暗部；
   - **通道 B（`lighter` / `screen` 加色暖橙辉光）**：在主炉、火把、马楠提灯、绒火狐处叠加**炽白琥珀内芯（`#FFE8B3`）→ 饱和暖橙中圈（`#F28533`）→ 柔和余烬外晕（`#B8441E`）**，带双频火焰摇曳，真实照亮周围木板纹理与角色暖边反光！
6. **L5 · 三景深暴雪粒子与失温冰晶暗角**
   - 暴雪夜粒子拆 3 层：远景细密慢飘雪粒 + 中景 `38°` 斜拉细长风雪线 + 近景高速半透明大雪雾团掠过屏幕；
   - 失温 `< 45` 时，屏幕四周渐显**半透明冰晶霜花暗角（Frost Vignette）**并随脉搏呼吸；回到暖区迅速消退并闪过一圈极轻暖橙回温微光。
7. **L6 · 沉浸式轻工艺 HUD（去除调试面板味）**
   - **移除底部常驻黑框**：“已载入 JSON 存档”等状态改为顶部居中 `2.8s` 自动淡出的细长轻提示 Toast；操作键提示精简放于左下极淡小条；
   - 左上角马楠卡片保留 `head-0~3` 原头像，升级为**紧凑生存仪表盘**：带暖橙/冰蓝渐变**体温条**、**生命条**、主炉燃料微条与等宽 `tabular-nums` 脚下温度读数；
   - 底部快捷栏全部配备**精绘 `32×32` 道具图标**、左上键位角标、右下库存数量角标与暖琥珀聚焦高光框。

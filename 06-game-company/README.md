# 06 · 马楠：通关游戏公司

2D 像素横版动作肉鸽（参考死亡细胞）。马楠是建模师兼地编，要从美术部一路打到老板办公室，准时下班。

- **楼层与 Boss**：1F 美术部（主美·改稿大师）→ 2F 研发部（制作人·需求变更）→ 顶层总裁办（老板·画大饼）
- **隐藏关卡**：打败老板后 Boss 房里出现货梯。走右边的门是普通结局；坐货梯先进茶水间整备（升级、售货机），再进入“天台 · 健身房”（两段地图，开头高级宝箱，必有实习生小卖部），最后挑战隐藏 Boss **刘敬阳**（3400 血）
  - 一阶段（中山装）：扔建模方块（落地裂成两道地波）、雕刻笔贴地冲刺（身后地面翻起黏土尖刺，跳起来躲）、回旋哑铃、哑铃砸地；贴身时哑铃上勾拳
  - 二阶段（半血，变身炎龙铠甲）：烈焰冲刺（留下火痕）、龙炎吐息、烈焰柱、炎龙天降（落点有提示）、升龙拳；四分之一血时龙魂爆发，召唤天火
  - 打败后是“真 · 下班”结局，存档记录击败次数
- **建模工具（J）**：雕刻笔、布尔锤、挤出长枪、切线刀、法线鞭（第三下把敌人拽过来）、剪切刀（剪中 3 次爆发）、渲染大剑（按住蓄力重斩）
- **地编工具（K）**：变换轴、植被笔刷、Ctrl+Z、熔岩材质球、碰撞体方块、预制体炮台、吸管工具（把敌人吸过来晕住）、关键帧（记录位置，再按瞬移回来）、阵列修改器（扇形三连发）
- **武器背包与切换**：建模、地编工具各能带 3 把，背包没满时捡到的武器直接放进去。按住 R（建模）/ F（地编）打开切换器：背景模糊、游戏进入子弹时间（0.12 倍速），J / L 或 ← / → 选择，松开 R / F 换上；切换器打开时按 Esc 取消。背包满了再捡就是替换当前那把
- **机制**：连击与翻滚无敌、二段跳、下劈、打回血、灼烧 / 缠绕 / 晕眩、武器等级与词缀、建模 / 地编 / 体力属性卷轴、心流连击、补模型隐藏宝箱、加急任务、准时下班门、茶水间升级与售货机、加班模式
- **动作**：按住跳更高（顶点滞空）、贴墙自动攀边、翻滚输入缓冲、翻滚中可预输入攻击、翻滚后立刻攻击打出冲刺斩（必暴击）、空中第一刀短暂滞空、每次出招可转身
- **换手斩**：用切换器换主武器后 3 秒内，第一下必暴击、击退更远（4 秒冷却）
- **评审会**：每层后段可能出现的封闭挑战房（1F 一半概率，2F、3F 75%）。走进去两侧封门，打完两轮（第二轮带精英）才开门，奖励高级武器 + 卷轴 + 便当 + 灵感，一半概率给图纸
- **天赋**：茶水间三选一里必有一个天赋，每个只能拿一次。自动保存（每层一次免死）、连锁报错（灼烧敌人死亡爆炸并传染）、热切换（换武器重置副武器冷却，换手斩 +50%）、截稿冲刺（低血量伤害 +45%）、甩锅（完美闪避时爆炸）、甲方好评（暴击回血）、加班费（每 10 杀最大生命 +5）、反向需求（受伤时震开身边敌人）
- **完美闪避**：翻滚刚开始的一小段时间里躲过攻击，触发子弹时间，下一击必暴击，心流 +3
- **韧性**：敌人出招（前摇、冲刺）时不会被普通攻击打断，要打空韧性才能破防；被打飞撞墙会额外受伤；同一时间最多两只怪出招（加班模式三只），怪物之间会互相推开
- **Boss**：持续输出攒满破绽槽（血条下方，约 25% 血量）后 Boss 失衡 1.8 秒、受伤 +25%；转阶段时怒吼震开玩家并清掉弹幕。贴身停留约 0.7 秒或 1.5 秒内连砍 5 刀，Boss 会用近身反击打飞玩家（主美红笔横扫、制作人需求冲击波、老板肚子顶人，起手头上闪“！”），二阶段起连两下；放远程招时被狂砍会中断施法反击。二阶段起新增主美“满屏批注”、老板“饼雨”（地上先出现落点），制作人“拉人开会”召唤小怪；老板三阶段 KPI 柱追着玩家长；主美二阶段连续冲刺，制作人三阶段双排激光，老板三阶段连续跳砸。平时贴身不掉血，只有冲撞类招式造成碰撞伤害
- **精英词缀**：精英怪随机带一个词缀，头顶显示名字。赶工（动作快 35%）、返工护甲（减伤 30%、韧性更高）、拆需求（死后分裂成两只小怪）、带薪摸鱼（2 秒没挨打就回血）、甩锅（死后 0.9 秒原地爆炸）。精英数量随楼层增加
- **加班合同**：每层一半概率出现紫色宝箱。打开给高级武器 + 卷轴 + 20 灵感，代价是击败 8 + 楼层×3 个敌人之前受到的伤害翻倍
- **图纸（局外解锁）**：切线刀、碰撞体方块、预制体炮台、渲染大剑、关键帧五件武器，以及人体工学椅、甲方满意、快捷键大师三个升级，一开始不会出现。精英 35%、普通怪 1.5%、Boss 必掉图纸，拾到后要活着走到茶水间或通关才入库，倒下就丢了
- **加班等级 0–5**：通关当前最高等级解锁下一级，标题画面用 ◀ ▶ 选择。1 敌人更硬更痛、Boss 更快；2 精英更多；3 便当只带 1 个；4 怪更多、同时出招的怪 +1；5 换楼层只回一半血。进度存在浏览器本地
- **敌人**：穿模怪、返工便签、打印机、Bug、报错弹窗、KPI 表、防火墙、会议邀请、喷漆罐（1F，喷漆留下减速油漆）、合并冲突（2F，瞬移到身后砍）、项目经理（顶层，给周围的怪加速、召唤会议邀请）
- **实习生小卖部**：每层中段 60% 概率出现，三件商品用灵感买：热咖啡（回 50% 血）、备用便当盒、灵感卷轴、武器打磨、神秘武器。价格随楼层上涨

图鉴：标题画面点“图鉴”，按分类查看全部武器、道具与事件、敌人、Boss、升级与天赋（隐藏大佬遇到后才显示）。通关、暂停、倒下画面都能回到主页。

服装：标题画面按 C（或点“服装”按钮）在冬季卫衣和夏季背心之间切换，选择会记住。夏季服装素材是 `player_summer_*`，某个动作没有夏季版时自动用卫衣版；素材到位前按钮不显示。需求见 `art/batch9_summer_brief.md`。

操作：A D 移动，空格跳（按住跳更高，空中再按二段跳，贴墙自动攀边），S+空格 下平台，空中 S+J 下劈，J 建模工具，K 地编工具，Shift 翻滚（翻滚后立刻 J = 冲刺斩），按住 R / F 切换建模 / 地编工具，Q 吃便当，E 拾取 / 互动，Esc 暂停。支持 Xbox 布局手柄。

## 开发

源码在 `src/`，按模块拆分：

| 文件 | 内容 |
|---|---|
| `engine.js` | 画布、输入（含手柄）、音效与音乐、粒子 |
| `art.js` | 角色、武器、敌人、Boss、场景装饰的程序化像素绘制 |
| `level.js` | 关卡生成、瓦片与碰撞 |
| `actors.js` | 玩家、武器、投射物、敌人、拾取物 |
| `bosses.js` | 三个 Boss 的 AI |
| `game.js` | 流程、镜头、HUD、菜单 |
| `shell.html` | 页面外壳与 UI 样式 |

版本号和更新内容写在 `src/version.js`：发新版本时在 `CHANGELOG` 最前面加一条，游戏标题画面会显示新版本号，“更新内容”按钮会提示玩家有新内容。

改完源码后运行 `python build.py`，会重新生成 `index.html`。图片默认按相对路径引用 `art/` 下的文件，所以发布或拷贝时要连同 `art/` 目录一起；需要单文件版本时运行 `python build.py --embed`，图片会全部内嵌（约 16MB）。

正式美术都在 `art/`：马楠（`player/`）、敌人（`enemy/`）、三个 Boss（`boss/`）、拾取物（`pickup/`）、投射物和特效（`fx/`）、武器图标（`ui/`）、三层场景的瓦片、背景和装饰（`scene/`）。文件名带 `@2x` 的是 2 倍精度素材，`anchors.json` 记录手部、笔尖等挂点。已经有正式素材的角色、敌人、Boss、武器、拾取物、投射物、场景，代码画的旧版都已删除；还没有素材的少数东西（货梯、部分地编工具的弹道和地面效果、刘敬阳变身的火焰龙卷和火龙）仍由代码绘制。还没接入的素材放在 `art/_pending/`，不会打包。美术需求见 [ART_SPEC.md](ART_SPEC.md) 和 `art/batch*_brief*.md`。

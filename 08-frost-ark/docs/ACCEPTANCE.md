# 《马楠：霜云方舟》M4–M6 统一验收

[GitHub Pages 在线试玩](https://shangzhenyu-cr.github.io/MaGame/08-frost-ark/) · [GitHub 开发分支](https://github.com/ShangZhenYu-CR/MaGame/tree/game/08-frost-ark/08-frost-ark)

建议使用电脑：`WASD` 移动，`E` 互动、采集、投喂，`F` 反击或拾取，`I` 打开背包／导入导出，`B` 建造，`V` 云兽伙伴，`N` 航图，`J` 图鉴。

1. **抓钩**：按住左键不放，暖色虚线逐渐伸长，末端圆环是当前实际射程。松手抛钩，按 Esc 可取消。寒潮和失温暗角下也能看见。 [对比实机图](https://drive.google.com/file/d/18yZZfKZhE5q7GjYT_QSVH-iY39C5Y2GQ/view)
2. **M4 驯兽**：先去微灯礁试岩甲鼹。打到虚弱或用麻痹冰网／霜铁兽夹控制，再喂它偏爱的烤块茎。研究「拾荒与供暖拓展」后建兽窝和饲料槽，用 V 切换随行、打工和休息。绒火狐随行有暖圈，霜角牦牛可背物资。 [截图与离线包](https://drive.google.com/drive/folders/1Xpqwvi9jDbhn6T8ahrJh0zHTE7We3fqB)
3. **M5 寒潮与风区**：第 5 天入夜会出现首轮大寒潮，防霜箭塔负责远射，火油喷射塔负责近处。两座塔在「霜城防线与生态园」中解锁，注意布置在能得到热量的位置。航图开放硫磺裂谷、永冻遗迹，可遇见熔核蜥和风暴翼龙。 [截图与离线包](https://drive.google.com/drive/folders/1aa3icV8dhTrwkCeJZKAlUKqOQsXSnC06)
4. **M6 终局**：收齐四枚天穹火种：霜松群岛的冻林门击败霜鬃领主，硫磺裂谷岛击败裂谷炎甲兽，在余烬熔窟和永冻遗迹群分别打开火种遗迹箱。到 Lv.2 主炉旁铸成太阳方舟，再去极光天穹。霜鲸出招前地面会有圈，躲开后靠近按 F，打完三阶段可继续无尽云海。 [截图与离线包](https://drive.google.com/drive/folders/1C1RxiNX6wdPAbeSYR3STwURpbUB6BOX3)

离线包要完整解压，再双击 `08-frost-ark/index.html`。电脑间转移存档时用背包的 JSON 导入和导出。要保留老档，请先导出一份再开始新档。

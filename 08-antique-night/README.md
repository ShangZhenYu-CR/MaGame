# 马楠：古玩夜行 · 青花瓶试玩章

打开 `index.html` 或通过 GitHub Pages 游玩，无需安装依赖。试玩版仅支持键盘和标准映射手柄，不支持触屏。

## 操作

- 移动：A / D 或方向键；手柄左摇杆。
- 跳跃：空格 / W / 上方向键；手柄 A。
- 雕刻笔：J；手柄 X。木槌重击：K；手柄 Y。
- 闪避：Shift；手柄 B。交互：E；手柄 A。
- 暂停：Esc；手柄菜单键。声音开关：M。

## 流程

在店里接待客人并检查青花瓶，进入瓶中山水，寻找三片青花碎片，解除画师护罩。击败画师回到店内，接近青花瓶并对准修复进度条，完成三次修复。到达落脚点后生命会恢复，死亡重试保留实际收集过的碎片。

瓷兽扑击前会预警；画师攻击也有预警，第二阶段会交替施放墨弹和地面笔划。手柄键位按标准映射，不同设备可能有差异。

## 目前状态

本章为持续开发中的试玩版：部分角色动作使用生成的关键帧，帧间细节仍需统一；敌人种类、地形、关卡叙事和战斗反馈仍需扩充。程序合成音频，音乐和音效可以用 M 静音。浏览器播放音频通常需要玩家先点击或按键。

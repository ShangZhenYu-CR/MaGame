## 一、世界观、主角与核心循环

### 1.1 世界设定与主角形象
- **世界观**：世界碎裂升空，化作被永冬风暴笼罩的无尽冰蓝云海与无数漂浮空岛。幸存者只能在碎裂浮石上燃起「余烬主炉」，边在云海漂流拾荒、边扩建浮空方舟、边收服耐寒云兽，穿越四大风区寻找「天穹火种」，平息永冬。
- **主角：马楠**（延续 MaGame 设定，参考 `../assets/character/design-sheet.jpg`）
  - **视觉识别**：短寸头、炭黑连帽防风外套（胸口浅灰 `A` 标）、黑色工装裤、浅灰白运动鞋；俯视像素精灵中突出炭黑连帽轮廓 + 暖橙提灯/工具微光，在冰蓝雪雾中一眼锁定。
  - **性格气质**：沉稳、靠谱、实干派（“踏实做事，好好生活”），提示与事件文案简洁克制带冷幽默。
  - **头像只读复用**：直接加载仓库现有 `../assets/character/head-0.png ~ head-3.png`：
    - `head-0.png`（平静）：常态探索/建造
    - `head-1.png`（微笑）：暖区回温、驯兽成功、收获作物、击败古兽
    - `head-2.png`（专注）：蓄力抛钩、登岛战斗、寒潮预警
    - `head-3.png`（冒汗）：体温告急、主炉燃料不足、甲板破损警报
- **初始吉祥物伙伴：小猫「拿铁」**
  - 开局蜷在余烬主炉旁烤火，兼任直观环境晴雨表（暖和打呼噜、暴雪逼近炸毛、主炉缺柴朝炉子喵叫提醒）；主炉升到 Lv.2 后解锁自动拾取主炉暖区内甲板掉落物。

### 1.2 三大玩法咬合闭环
1. **没有暖区，一切停摆**：极寒夜与大寒潮来袭时，离开暖橙热场的机器结冰停机、温室冻毁、驯兽缩窝罢工、马楠持续失温掉血。扩建挡风墙与热力中继塔是生存刚需。
2. **没有驯兽，产能与远征卡脖子**：前期手搓抛钩、砍树、添柴；中期必须登岛驯服云兽——绒火狐添柴加温、岩甲鼹破冰挖矿、风爪鸥出海叼残骸、霜角牦牛移动仓库＋产保暖绒毛。
3. **没有航行登岛，方舟无法升阶**：必须驾着整座浮空方舟驶入更深风区，靠泊高危浮岛获取稀有矿脉、驯服高阶巨兽、夺取「天穹火种」。

## 二、核心系统规格

### 2.1 双层级空间与云海航行
- **方舟网格（`ArkGrid`，上限 `48×48`，每格 `32×32px`）**：开局中央 `7×7` 浮木甲板 + 中央 `2×2` 余烬主炉 + 舵轮 + 储物箱。受浮力预算约束（浮力核心提供上限）；挡风墙/保温墙可降低热扩散损耗 `45%–65%`。
- **云海漂流拾荒（`CloudStream`）**：按风向漂来浮木板、冻铁废件、冰晶碎块、旧缆绳、漂流货箱、冻肉。前期用蓄力抓钩（带预瞄轨迹）拉回；中期用捕捞网栏 + 分拣臂自动化。
- **云海航图与浮岛远征（`SkyMap` + `IslandGrid`）**：舵轮切换停泊/巡航；靠泊浮岛按 `E` 搭跳板无缝登岛。浮岛按种子生成 `64×64` 局部网格，离岛后仅存稀疏差分。
- **四大风区**：`碎云浅海 (T1)` → `霜松群岛 (T2)` → `硫磺裂谷岛 (T3)` → `永冻遗迹与极光天穹 (T4)`。

### 2.2 实时热力场、光照与寒潮节律
- 白昼 `-4°C`、暴雪夜 `-22°C`、每 5 天一次大寒潮（Whiteout）`-55°C`。
- `heatField.ts` 在活跃格内以 `4Hz` 迭代热扩散与挡风墙隔热。
- `>= 15°C` 温暖回温且机器 `100%` 效率；`< 0°C` 掉体温且机器减速至 `40%`；`< -20°C` 机器冻结停摆，体温归零持续掉血。

### 2.3 方舟驯兽与活体基地（7 种核心云兽）
用麻痹冰网/压低血量至 `35%` 以下触发虚弱 → 靠近按 `E` 投喂对应热食诱饵 2–4 次收服 → 建暖区兽窝后一键切换 `随行出战（上限 3 只）/ 基地打工 / 休整回温`：

| 生物 | 风区 | 偏好诱饵 | 基地打工 | 随行出战 |
|---|---|---|---|---|
| 岩甲鼹 (`burrowback`) | T1 | 烤块茎 | 砸原矿提产 | 自动挖硬矿、近战破甲 |
| 绒火狐 (`emberfox`) | T1 | 烤肉干 | 自动给主炉/熔炉添柴 (`+25%`) | 半径 3 格移动暖橙热场 |
| 风爪鸥 (`galehawk`) | T1–2 | 腌云鱼 | 飞出甲板自动拾荒 | 扩大航图视野、俯冲致盲 |
| 霜角牦牛 (`frostyak`) | T2 | 暖草团 | 产保暖绒毛、修补外墙 | `+12` 格移动仓库、冲撞击退 |
| 雪林鹿 (`glacierstag`) | T2 | 暖莓汤 | 温室作物增速 `+60%` | 周期回温＋回血光环 |
| 熔核蜥 (`magmalisk`) | T3 | 熔晶肉排 | 免燃煤供能高级熔炉、融冰 | 扇形火线喷吐 |
| 风暴翼龙 (`tempest_wyvern`) | T4 | 秘银炙肉 | 提供浮力与航速 `+35%` | 高伤风刃、终局主力 |

### 2.4 终局目标
收集 4 枚「天穹火种」升级主炉为「太阳方舟」，前往极光天穹击败三阶段终局 Boss **「永冬霜鲸」**，解锁通关结算与无尽云海模式。

## 三、视觉美学与交互工艺规范

- **色彩基调**（锁定于 `src/render/palette.ts`）：低眩光冰蓝石墨（`#0C1520` / `#152436`）对撞克制暖琥珀（`#FFD08A` / `#EA7A30` / `#9C3D1C`），暗石板 UI（`#18202B` / `#212C3A`）+ 松青确认色（`#38A89D`）。
- **硬性禁令**：严禁 `#000000` 死黑、蓝紫渐变、霓虹外发光、Emoji 充当 UI 图标；所有数字强制等宽 `tabular-nums`。
- **渲染与美术管线（v2.0 升维，详规见 `docs/ART_SPEC.md`）**：
  - 主体资产（角色、拿铁、建筑、甲板/浮石、残骸、UI 图标、云兽与 Boss）统一采用 **高精 2.5D 手绘 3/4 俯视精绘 PNG 资产管线**（`imagegen` + `scripts/process-art.py` 去背净边、锚点对齐、轻量压缩，总资产 `≤ 4.5 MB`），彻底淘汰纯 `fillRect` 堆块；
  - 画面氛围采用 **7 层电影级 Canvas 2D 渲染**（柔和高空视差云海 + 立体浮石锥底与自动外缘护栏 + 实时热力结霜覆层 + 接触影与 Y-Sort + 双通道冷压/加色暖橙辉光 + 三景深斜向风雪与失温冰晶暗角 + 图标化生存仪表 HUD）。
- **交互工艺**：按钮热区 `>= 28px`、Tooltip 预热切换、建造网格吸附虚影、4 秒无打断拆除撤销条、`Esc` 逐层退栈。

## 四、技术架构与三道验收门禁

- **技术栈**：`TypeScript (strict) + Vite + HTML5 Canvas 2D + Web Audio`，纯静态输出（`npm run build` 自动同步 `08-frost-ark/index.html` 与 `dist/`）。
- **四层解耦**：`src/data/`（JSON 数据表）→ `src/sim/`（纯 TS 无头引擎，零 DOM/Canvas 依赖）→ `src/render/`（只读渲染）→ `src/ui/`（轻量 HUD）。
- **三道强制门禁**：
  1. `npm run check:data && npm run typecheck && npm run build`
  2. `npm run test:sim`（Node 确定性与生存闭环无头验证）
  3. `npm run test:e2e`（Playwright 实机零报错 + 截图肉眼检查）

完整分阶段任务见根目录 `MILESTONES.md`，Dot 执行纪律见 `DOT_RULES.md`。

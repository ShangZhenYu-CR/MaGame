# 马楠·鬼剑传 · 1.2 功能粗稿

电脑端动作游戏：五节幽灵列车、普通与挑战、六技能六分支、追空/破阵/守灯构筑、十二装备部位、制作、训练场与玩家交易规则。美术暂用程序粗稿。

## 当前方向

先试玩打磨战斗手感、数值、界面和流程，再做在线联机。两种入口共用战斗、物品与构筑代码，美术保持粗稿。

| 版本 | 运行与存档 | 玩家交易 |
|---|---|---|
| [GitHub Pages 网页试玩](https://shangzhenyu-cr.github.io/MaGame/07-ghost-sword/) | 无需安装；Worker 执行战斗，IndexedDB 保存到当前浏览器 | 不开放跨玩家交易，不生成虚假订单；所有构筑材料可自行打怪取得 |
| Node 开发版 | 本机 Node 服务 + SQLite；保留原有开发能力 | 保留真实共享市场、竞拍、批购与并发结算 |

网页与开发版存档独立，不跨设备同步，也不互相覆盖。网页每60个战斗帧及关键操作保存，刷新回到最近已提交状态并暂停；普通关闭网页没有开发版的10分钟断线处罚。写入等待冻结战斗，提交成功才确认操作；写入失败停止模拟，可从已提交存档恢复。同一网站仅允许一个游戏标签页持有写入权。清除网站数据或使用临时浏览模式可能丢失该浏览器存档。

网页使用现代电脑浏览器（支持模块 Worker、IndexedDB、Web Locks 和 import map），通过 HTTPS 或 localhost 打开。两版目前都没有组队战斗或多人实时联机；本机服务仍只监听 `127.0.0.1`。

## 开发版启动

1. 安装 Node.js 24 LTS（验收使用 24.18.1）。
2. 在本目录打开终端，首次运行 `npm ci` 安装依赖。
3. 双击 `Start.cmd`，或执行 `npm start`。
4. 浏览器访问 http://127.0.0.1:8765/ 。关闭服务终端即可停止。

不要双击 `client/index.html`；它需要本机服务。仓库根目录下本游戏的 `index.html` 是网页试玩入口，需经静态 HTTP 服务打开。端口8765被占用时，请先关闭另一份鬼剑传服务。

新下载的副本从新角色开始。本机存档位于 `runtime/ghostsword.sqlite`，不随仓库上传。角色钥匙可在游戏设置中复制保存；不要公开分享。不同浏览器角色连接同一台本机服务时共用该市场。

## 操作

方向键移动，双击横向键奔跑；X普攻，C跳跃/倒地受身，V格挡，空格后跳/受击脱身，Q抓取；Z/A/S/D/F/G技能，1/2药剂，Esc暂停。支持改键，失焦自动暂停。

## 代码与部署

- `shared/`：两版共用战斗、装备、制作和背包规则。
- `client/`：共用界面；`socket.js` 连接开发服务。
- `browser/`：网页版执行线程与浏览器存档。
- `server/`：开发版网络、SQLite 持久化、真实市场。
- Pages 使用 `main` 分支根目录直接发布，无额外构建。原开发目录与其 SQLite 存档保持独立，不随上传迁移。

双版本回归已核验网页命中取消、浮空、冷却与刷新恢复、多标签互斥，以及开发版缺料拒绝、交易交付、请求去重和结算只写一次。上方完整通关与20组交易记录属于双版本拆分前的1.2开发版验收，不冒充网页版全流程重测。

# 马楠：通关游戏公司 · 美术第十批需求（武器个性：收起 / 持握 / 招式特效）

给出图的同学（GPT）：本文档自包含。做完把 zip 放回本目录 `/MaGame/06-game-company/art/`，命名 `manan_weapon_style.zip`（太大可以拆成 `_a` `_b` `_c`）。

## 一、目标

现在所有武器拿在手里的样子都差不多：单手握着，跑步时斜扛在肩上。这一批让**每把武器一眼就能认出来**，分三件事：

1. **收起状态**：没在打架的时候，武器放在身上固定的位置（背后、腰上、耳朵后面……），每把武器不一样
2. **持握状态**：遇到敌人或开始攻击时，马楠把武器拔出来，用这把武器特有的姿势拿着（单手、双手、反握、拖地……）
3. **招式特效**：每把武器的攻击都有自己的特效，看特效就知道是哪把武器

游戏里的规则（帮你理解动作怎么衔接）：

- 身边 150 像素内没有敌人、并且 2.5 秒没攻击 → 播放“收起”动作，武器回到收起位置
- 敌人靠近或按下攻击 → 播放“拔出”动作（攻击时会跳过，直接出招），进入持握状态
- 跳跃、翻滚、攀边、吃便当时武器保持当前状态（收起的就还在背上，拿着的就还在手里）

**和第八批的关系**：第八批 B 组里法线鞭、剪切刀、渲染大剑的攻击动作，**以本批的描述为准**（本批更具体）。第八批 A 组（手持图、图标）、C 组（新敌人）、D 组（小卖部）不变。

## 二、统一规格（和之前相同）

- **2 倍精度**：下文尺寸都是逻辑尺寸，**实际按 2 倍像素出图**，文件名加 `@2x`。坐标按 2 倍像素写，原点为每帧左上角，x 右 y 下
- 像素风，透明背景 PNG，朝右，横向等宽序列帧，帧间不留空，外轮廓 1 像素 `#14121a`，左上光源
- 马楠每帧 48×48（实际 96×96），站立约 42 像素高，脚底中心对齐每帧底边中点，**人物大小和现在的动作完全一致**
- 武器图朝右画；特效图朝右画（游戏会自动左右翻转）
- 附 `README.txt`：每个文件帧数、每帧含义、没做完的部分

## 三、A 组 · 通用部分（所有武器共用，必做）

### A1 · 身体挂点表 `carry_anchors.json`

收起的武器要贴着身体跟着动，需要知道每一帧身上几个点的位置。请给下面这些**现有动作的每一帧**标出 3 个点：

- `back`：后背两肩胛骨中间（背在背后的武器挂这里）
- `hip`：右侧腰带的位置（挂在腰上的武器挂这里）
- `ear`：右耳后面（雕刻笔夹这里）
- `tilt`：这一帧上身前倾的角度，单位度，向前倾为正（跑步一般 10 左右，站立 0）

要标的动作：`player_idle`、`player_run`、`player_jump`、`player_fall`、`player_land`、`player_djump`、`player_roll`、`player_hurt`、`player_mantle`、`player_heal`、`player_parry`、`player_spray`、`player_dive`、`player_dive_land`、`player_atk_dash`

格式：

```json
{
  "player_idle": {
    "back": [[40,44],[40,45],[40,45],[40,44]],
    "hip":  [[52,66],[52,67],[52,67],[52,66]],
    "ear":  [[54,26],[54,27],[54,27],[54,26]],
    "tilt": [0,0,0,0]
  }
}
```

（数字只是示意，按实际图标；坐标是 96×96 帧里的 2 倍像素坐标。翻滚的帧里身体蜷成球，点标在球上大概的位置就行。）

### A2 · 新的通用动作（每帧 48×48，每帧给手的位置）

| 文件 | 帧数 | 说明 |
|---|---|---|
| `player_hold2_idle` | 4 | **双手持握待机**：两手一前一后握在身体前方腰部高度，重心压低，膝盖微屈，随呼吸轻微起伏。给布尔锤、挤出长枪、剪切刀、渲染大剑用 |
| `player_hold2_run` | 8 | **双手持握跑步**：两手保持在身前，上身前倾，腿的动作和现在的跑步一致 |
| `player_draw_back` | 4 | **从背后拔出**：右手伸到右肩后面 → 抓住 → 往前一抽 → 摆出持握姿势。倒着播放就是“收回背后” |
| `player_draw_hip` | 4 | **从腰上拔出**：右手按到右腰 → 抽出 → 甩到身前。倒着播放就是“插回腰上” |

每帧的手的位置写进 `anchors.json`。双手动作请给**两只手**：

```json
{
  "player_hold2_idle": {"front": [[60,58],...], "back": [[50,60],...]},
  "player_draw_back":  [[44,30],[42,24],[56,40],[62,52]]
}
```

## 四、B 组 · 七把建模工具的个性（按顺序做，剪切刀优先）

每把武器要的东西：

- `weapon_<名字>_rest`：**收起时**挂在身上的样子（已经摆好角度的整张图，朝右的人身上看到的样子），再给一个挂点 `mount`：图上哪个点对准身体的 `back` / `hip` / `ear`
- 持握状态需要的武器图（大部分直接用现有的手持图 `weapon_<名字>`，下表注明了需要新画的）
- 攻击特效

`anchors.json` 里武器的写法：`{"weapon_shears_rest": {"mount": [x,y], "layer": "behind"}}`，`layer` 是 `behind`（画在人后面）或 `front`（画在人前面）。

### 1. 剪切刀 shears（最优先，招式参考“巨型裁缝剪刀连剪”）

| 项目 | 要求 |
|---|---|
| 收起 | **合拢后斜背在背后**，刀尖朝左下，两个把手的圆环从右肩上方露出来。`weapon_shears_rest` 32×32，挂 `back`，`behind` |
| 持握 | **双手各握一个把手**，剪刀横在身前，刀刃半张，平时会一张一合地“咔嚓”。新画 `weapon_shears_hold` 4 帧 32×32：半张 → 张开 → 半张 → 合拢，循环播放；每帧给两个握点 `grip1`（前手）`grip2`（后手）。人物用 `player_hold2_idle/run` |
| 攻击 | 重画 `player_atk_shears`：**每按一下是连续两剪**。2 段 × 6 帧 = 12 帧：张开 → 往前一剪（合）→ 再张开 → 再一剪（合）→ 张开 → 收回。两手一直分别握着两个把手，动作快、有节奏感，像裁缝剪布一样“咔嚓咔嚓”。每帧给两只手的位置 |
| 特效 | `fx_snip`：3 帧 24×24，每剪一下在刀口出现一个粉色（`#ff7ab0`）细长的“×”形剪痕，然后散成小碎布片<br>`fx_snip_burst`：6 帧 64×64，同一个敌人被剪满时触发：一把巨大的半透明粉色剪刀虚影在敌人身上“咔嚓”合拢，留下一个大 × 和飞散的布条 |

## 五、C 组 · 地编工具（有余力再做，可以留到下一批）

地编工具是一按就用的道具，不需要收起状态，只要“拿出来用”的那一下有特色：

| 工具 | 要求 |
|---|---|
| 变换轴 | `player_throw` 3 帧：侧身甩手扔出去（通用投掷动作，熔岩材质球也用这个） |
| 碰撞体方块、预制体炮台 | `player_place` 3 帧：弯腰把东西放到面前地上 |
| 吸管工具 | `fx_eyedrop` 4 帧 64×16：一条绿色吸管光束从手上伸出去，再缩回来 |
| 关键帧 | `fx_keyframe` 4 帧 32×32：紫色菱形标记出现时的展开动画（记录位置时）和收拢动画（瞬移回来时倒放） |

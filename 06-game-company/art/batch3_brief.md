## 一、统一规格（和前两批一样，继续保持）

- 像素风，透明背景 PNG，朝右，横向等宽序列帧，帧间不留空
- 外轮廓 1 像素 `#14121a`，左上光源
- 马楠每帧 48×48，站立时人物约 42 像素高，脚底中心对齐每帧底边中点
- 每个动作单独一个 PNG；GIF 预览可以继续附带
- zip 里附一个 `README.txt`，写清每个文件的帧数和每帧含义

### 新增：挂点文件 `anchors.json`（必须提供）

所有攻击、持武器的动作，都要给出**每一帧前手（握武器的那只手）的位置**，坐标以每帧左上角为 (0,0)，x 向右、y 向下：

```json
{
  "player_atk_stylus": [[33,20],[36,27],[29,21],[31,21], ...],
  "player_dive": [[28,34],[28,34],[28,34]]
}
```

武器手持图也写进同一个文件，给出握持点：

```json
{ "weapon_marker": {"grip":[4,19]} }
```

## 二、前两批的反馈

前两批已经全部接进游戏，整体效果很好，人物形象稳定。需要返工的：

1. **翻滚 `player_roll.png` 比例偏大（必须返工）**：第一帧蹲姿的头顶和站立时一样高，缩成球的几帧也接近站立身高，在游戏里翻滚时人物像突然变大了。请按站立时的比例重画：蹲姿约 30 像素高，缩成球的帧约 26 像素宽、24 像素高。帧数不变（6 帧）。
2. **雕刻笔第二、三刀手形是拳头（必须返工）**：游戏里会把笔挂在手上，拳头配笔看起来不对。请重画 `player_atk_stylus.png` 全部 12 帧，手是**握笔**的手形（四指环握、拇指扣住），并在 `anchors.json` 里给出每帧手的位置。第一刀的动作可以保留，只改手形。
3. **待机 `player_idle.png` 动作太小（建议）**：四帧几乎一样，游戏里看不出呼吸。请让肩膀和头随呼吸上下动 1 像素，第 3 帧闭眼。
4. **跑步（建议）**：左右腿交替还不太自然，有余力可以重画，没有就先不管。

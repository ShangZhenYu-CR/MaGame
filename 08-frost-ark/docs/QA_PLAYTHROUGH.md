# 《马楠：霜云方舟》M0–M6 实机巡检

测试日期：2026-11-27。试玩构建：[GitHub Pages](https://shangzhenyu-cr.github.io/MaGame/08-frost-ark/)（源码 `1aaf70b`，Pages `08954b9`）。组合使用相同构建的网页和离线双击入口；自然新档和“用准备档快速进入某个玩法”分开记录。实机操作均由浏览器按键或点击；准备档设定初始位置、材料或进度，不代替后续的实际操作。

## 已发布的移动修复

- 开局储物箱原先从北侧未碰到底座就停下。现在按箱子的实际着地范围挡路，从北侧走近、转向、沿护栏右侧绕到箱前均通过；仍不能穿箱，也没更改建造占格、储物交互或存档结构。
- 逐四向检查了全部 17 类船上实体的接触边界与余隙，独立检查窄通道、斜角、原始甲板边缘与靠泊移动。已经踏回船、脚仍跨接缝时收跳板，角色先退少许再折板；已卡在旧存档接缝可向左退出来。
- 全套 `npm run gate`、两个 `file://` 入口、公开 Pages 文件检查及公开构建上的储物箱／跳板复走通过。

## 已发现的剩余问题

| 优先级 | 复现现象 | 玩家受影响 |
| --- | --- | --- |
| 高 | 新档在微灯礁冻到 0 血后仍能走路、继续砍树，系统没有倒地或返场提示；战斗则拒绝 0 血出招。 | 生命归零后不清楚当前状态与怎么恢复。 |
| 中 | 带齐冻铁废件和旧缆绳，背包有火把、手斧、矿镐等入口，却没有数据表中的「制作抓钩」。 | 配方无法由现有正常操作触达。开局自带抓钩还可用。 |
| 中 | 右舷跳板与箱子提示重叠：底部仍说按 E 存取，登岛卡同时写按 E 搭板，实际 E 执行搭板。 | 玩家无法仅从底部提示判断 E 将触发什么。 |
| 低 | 指针在甲板上时，用 N 打开再关闭航图，关闭后仍弹出「打开航图」气泡。 | 遮挡画面和操作提示，非功能性卡死。 |
| 低 | 方舟左侧中段多拼一格，局部底部凭空垂挂一个大型浮石锥和冰凌。 | 扩建侧边破坏了底边长冰凌、侧边薄包边的美术规则，脚下甲板仍可走。 |

## 实机覆盖结果

| 内容 | 测过的操作与结果 |
| --- | --- |
| 开局、热力与美术 | 实际投钩、勾回缆绳和块茎，储物箱存取，扩木甲板并走上去，拆除及 4 秒内撤销，添柴、失温、回船回温、摆火把和挡风墙。另检查暴雪夜、结霜暗角、近镜头与滚轮缩放、图标、升 Lv.2 和拿铁暖区拾捡。 |
| 建造、浮力与自动化 | 逐一实际放置建造菜单的 17 项，包括加固铁甲板（在现有木板上升级）、木工台、熔炉、灶台、热力中继塔、捕捞网、分拣臂、玻璃温室、暖绒墙、浮力核心、兽窝、饲槽及两款炮塔。覆盖木工台研究、负重/材料限制、网栏转存货物、炉子完工领取、温室培育及冷停机。 |
| 道具工艺 | 每项库存变化确认，手斧、矿镐、耐久、两款霜铁升级、防风火把、冶炼、两个束缚道具、七款料理、两种作物和暖粮实测。19 条数据配方中 18 条取得成品，抓钩没有制作入口。实机用满背包采木，木材未被清空、手斧耐久未减。 |
| 云海远征 | 航图设航向、出发、自动靠泊、搭跳板、WASD 进岛前段的资源区、回船收板。另测试甲板斜对角与窄道边界；砍树、开箱、矿镐采矿与耐久、存读档及导入导出。 |
| 云兽 | 7 种都用正确诱饵实际驯服：岩甲鼹、绒火狐、风爪鸥、霜角牦牛、雪林鹿、熔核蜥和风暴翼龙。实际在伙伴页分工、加饲料，核实多产霜铁、添柴、叼残骸、修墙产绒、温室 1.6 倍、无煤冶炼和浮力 64→86；牦牛行囊存取往返成功；第 4 只随行被正确拦住，换下 1 只后能补入。 |
| 大寒潮与四枚火种 | 从第 5 天预警档实际守完三波，两座塔都开火，敌人清零，角色剩约 93 血。准备档中以 F/WASD 各打完满血霜鬃领主、裂谷炎甲兽，拿到对应火种；余烬熔窟、永冻遗迹群各实际开箱一次获得火种，重复按 E 不会再领。 |
| 太阳方舟与终局 | 先测未升阶锁极光天穹、主炉铸造。随后从极光天穹的准备档开战，三阶段未跳阶段或预先减血，实际用键盘移出冰圈、等破绽按 F，最后约 19 血战胜，点击进入无尽。图鉴建筑、云兽类别实际打开。 |

这些是电脑键鼠实测，不是手机触屏、所有随机种子或所有 64×64 地形格子的遍历。定向实机有准备档；长线自然档的进度另记。

## 航图逐岛检查

以下均实际按航图巡航、自动靠泊、搭跳板、走进岸边后的第一段资源区，再回到船上收跳板。近岸区通路通过，不代表逐格穷举地形。

## 连续自然新档与偏离

同一新档、不补材料或调整人物状态：抓钩试投并回收物资，扩甲板和撤销，制作手斧并用到掉耐久，实际去微灯礁及冷帆浮岛砍树、开箱和回船；回船用采回来的木材装木工台、解锁 T2、做火把、挡风墙，并观察回温恢复生命。0 血状态在两个岛均复现；回到炉边添柴后能缓慢回血，不是永久锁档。

【偏离报告】同一个自然新档未通关；第 5 天、晚期稀有材料、各兽分工和终局用准备档加速进入，再在浏览器正常操作测试。未把专项实机标为自然通关。除了已上线的移动修复，其余发现的缺陷只复现并记录，未在此轮改动；建议优先理顺 0 血反馈和恢复规则。

# 马楠·鬼剑传 · 1.2 功能粗稿

电脑端动作游戏：五节幽灵列车、普通与挑战、六技能六分支、追空/破阵/守灯构筑、十二装备部位、制作、训练场与玩家交易规则。美术暂用程序粗稿。

## 当前方向

先本地试玩，打磨战斗手感、数值、界面和流程，再考虑在线联机。保留已实现的交易规则与本机共享市场；目前没有公网部署、组队战斗或多人实时联机。服务只监听 `127.0.0.1`。

## 启动

1. 安装 Node.js 24 LTS（验收使用 24.18.1）。
2. 在本目录打开终端，首次运行 `npm ci` 安装依赖。
3. 双击 `Start.cmd`，或执行 `npm start`。
4. 浏览器访问 http://127.0.0.1:8765/ 。关闭服务终端即可停止。

不要双击 `client/index.html`；它需要本机服务。GitHub Pages 上的本目录页面仅为启动说明。端口8765被占用时，请先关闭另一份鬼剑传服务。

新下载的副本从新角色开始。本机存档位于 `runtime/ghostsword.sqlite`，不随仓库上传。角色钥匙可在游戏设置中复制保存；不要公开分享。不同浏览器角色连接同一台本机服务时共用该市场。

## 操作

方向键移动，双击横向键奔跑；X普攻，C跳跃/倒地受身，V格挡，空格后跳/受击脱身，Q抓取；Z/A/S/D/F/G技能，1/2药剂，Esc暂停。支持改键，失焦自动暂停。
